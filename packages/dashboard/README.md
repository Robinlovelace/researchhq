# `@researchhq/dashboard`

Interactive Svelte 5 + SvelteKit 3 (`@sveltejs/kit` `adapter-static`) + Tailwind CSS v4 research portfolio and future-publications planning dashboard for [ResearchHQ](https://github.com/Robinlovelace/researchhq).

## Key Features

- **Overview & 5 Stages of Open Science Scorecard:** Dual-provenance citation switching (OpenAlex + Google Scholar), `h-index`, `i10-index`, Field-Weighted Citation Impact (`FWCI`), interactive Stage 1-5 reproducibility cards, and actionable Open Science Upgrade Opportunities.
- **Time Series (Past & Future):** Stacked annual output and citation trajectories extending seamlessly into planned submission quarters and target publication years.
- **Journals & Venue Metrics:** Hybrid OpenAlex + curated Clarivate JIF / SJR quartile / CiteScore sortable table and JIF-vs-OpenAlex 2-year citedness scatter plot.
- **Publications Explorer:** Container-queried responsive table collapsing cleanly to mobile cards (`375px`), multi-facet filtering, and one-click BibTeX export.
- **Future Papers Pipeline & Quick `% Complete` Updater:** 4-lane Kanban board and Target Journal Matrix displaying each planned paper's **Percent Complete (`readinessPercent`)**, inline `-10%` / `+10%` steppers, detail modal progress slider + status selector with `localStorage` preview persistence, one-click `npx @researchhq/cli update-idea` command generation, and an interactive **New Paper Idea** composer (`IdeaComposerDialog.svelte`).
- **Shareable Deep Links, `?embed=1` Mode, `?demo=1` Fixture & Schema.org JSON-LD:** URL query state (`?tab=&stage=&venue=&q=&pub=&paper=`), compact headerless iframe embedding (`?embed=1`) for Quarto/university pages, synthetic multi-researcher demo persona (`?demo=1` loading `static/data/demo-portfolio.json`), and XSS-safe `Person` + `ScholarlyArticle` JSON-LD metadata.

## Adding & Updating Papers: Zotero, AI Agents, and Researcher Judgement

The dashboard reads `static/data/portfolio.json` generated by [`@researchhq/cli`](../cli/README.md) from `data/planned-papers.yaml`, `data/journal-metrics.yaml`, and `data/overrides.yaml`:

- **Quick `% Complete` updates:** Adjust completion percentage interactively on any planned paper card (`-10%` / `+10%`) or via the slider inside the paper detail modal, then copy the generated `npx @researchhq/cli update-idea --slug '<slug>' --readiness <pct>` command to persist the update to `data/planned-papers.yaml`.
- **Adding new paper ideas:** Click **New Paper Idea** in the top bar to draft a new planned paper with live Zod schema validation and copy either the YAML entry or the `npx @researchhq/cli add-idea` command.
- **AI Agents & Zotero + Human Input:** AI agents connected to your Zotero library (`references.bib`, PDF notes, Zotero MCP) and OpenAlex can pre-populate historical works, `@citekey` references, and candidate literature gaps. However, **future planned papers always require researcher input** to judge realistic `% complete` readiness, agree authorship and data-release timing, and choose appropriate target journals based on readership fit, Open Access / APC models, and review speed.
